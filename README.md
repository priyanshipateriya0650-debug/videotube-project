# VideoTube – Video Sharing Platform

A full-stack video-sharing platform where users can upload, watch, and interact with videos.

## Live Demo

**Website:** https://videotube-project-cryswvqgx.vercel.app/

## Features

- User authentication (JWT)
- Upload and manage videos
- Like and unlike videos
- Add and manage comments
- Create playlists
- Tweet functionality

## Tech Stack

- **Frontend:** React.js, Vite, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose
- **Media Storage:** Cloudinary
- **Authentication:** JWT

## Deployment

- Frontend: Vercel
- Backend: Render
- Database: MongoDB Atlas
